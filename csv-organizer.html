3지번 자동 채우기

CSV에 담긴 위도·경도를 실제 주소로 바꿔 건물지번 칸을 채웁니다. 한 번 찾은 곳은 기억해 두었다가 다음에 다시 쓰지 않습니다.

아직 실행하지 않았습니다.
정확 지번 모드 — 카카오 무료 키 넣기 (선택)

키 없이도 동 이름·도로명까지는 자동으로 채워집니다. 번지(123-4)까지 정확히 채우고 싶으면 카카오 키를 한 번만 넣어 두세요. (무료, 하루 30만 건)

  1. developers.kakao.com 접속 → 카카오 계정 로그인
  2. 내 애플리케이션 → 애플리케이션 추가하기 (이름은 아무거나, 예: 우리부동산)
  3. 만들어진 앱 → 앱 키 화면의 REST API 키를 복사
  4. 같은 앱의 카카오맵 항목을 ON으로 바꾸기 (이게 꺼져 있으면 주소가 안 나옵니다)
  5. 아래 칸에 붙여넣고 저장

키는 이 브라우저에만 저장되고 홈페이지 파일에는 들어가지 않습니다. 다른 컴퓨터에서 쓰시면 그 컴퓨터에서 한 번만 다시 넣으면 됩니다.
