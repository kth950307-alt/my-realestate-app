⚙ 연결 설정 (한 번만 하면 됩니다)

매물 장부는 공개 저장소에 두지 않습니다. 사장님 구글 계정의 Apps Script를 거쳐서만 읽고 씁니다.

준비물 1개 — 매물 등록·수정용 Apps Script입니다. 아래 [설치 안내]를 펼쳐 ① 코드 복사 → ② script.google.com 새 프로젝트에 붙여넣기 → ③ 웹 앱으로 배포 → 나온 주소를 위 칸에 붙여넣으면 끝입니다.
(손님 리마인드와 별도 프로젝트입니다. 비밀번호는 같은 563011을 그대로 쓰면 됩니다.)
📋 설치 안내 & Apps Script 코드 보기 (3단계)
① script.google.com → 새 프로젝트 → 아래 [코드 복사]를 눌러 편집기에 통째로 붙여넣기
② 코드 맨 위 PASSWORD가 사장님 비밀번호(563011)인지 확인 (바꾸려면 여기서)
③ 배포 → 새 배포 → 웹 앱, 실행 계정 ‘나’, 액세스 권한 ‘모든 사용자’ → 배포 → 나온 웹 앱 URL(.../exec)을 위 칸에 붙여넣고 [연결 확인]
코드를 고치면 [배포 → 배포 관리 → 연필 → 새 버전]으로 다시 배포해야 반영됩니다.
