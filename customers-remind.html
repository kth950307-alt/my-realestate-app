⚙ 연결 설정 (한 번만 하면 됩니다)

손님 명단은 공개 홈페이지에 두지 않습니다. 사장님 구글 계정의 Apps Script를 거쳐서만 읽고 씁니다.

준비물은 딱 하나 — 구글 스프레드시트에 붙일 Apps Script입니다. 아래 [설치 안내]를 펼쳐 ① 코드 복사 → ② script.google.com에 붙여넣기 → ③ 웹 앱으로 배포 → 나온 주소를 위 칸에 붙여넣으면 끝입니다. 비밀번호는 코드 안(PASSWORD)에서 바꿀 수 있고, 확인은 서버(Apps Script)에서 합니다.
📋 설치 안내 & Apps Script 코드 보기
① script.google.com → 새 프로젝트 → 아래 코드를 통째로 붙여넣기
② 코드 맨 위 PASSWORD를 사장님 비밀번호로 바꾸기 (지금은 563011로 되어 있습니다)
③ 배포 → 새 배포 → 웹 앱, 실행 계정 ‘나’, 액세스 권한 ‘모든 사용자’ → 배포
④ 나온 웹 앱 URL(.../exec)을 위 칸에 붙여넣고 [연결 확인]
